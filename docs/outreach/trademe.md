To: api@trademe.co.nz

Subject: WorthIt proposal for transient listing comparisons and explainable rankings

Kia ora Trade Me API and Legal teams,

I am [Robin's full name], [role] at [legal entity]. We are developing WorthIt, a New Zealand comparison project. Would Trade Me consider written approval for the limited use below? We understand your published guidance restricts buyer tools and price monitoring requests, so this is a request for an express exception, rather than an assumption that ordinary API access permits our proposal.

We propose to retrieve only approved public listing fields through your approved API for each use, process them in memory for a comparison, and display an attributable source link and an explainable ranking. For example, an explanation could identify the price and factual specifications that influenced a result. We would not retain listing copies in a database, cache, logs or analytics, build price histories, copy images or descriptions, or act on a member's behalf. The design would need to enforce these limits before any pilot. Please specify permitted transient handling, displayed fields and deletion requirements.

We recognise that clause 37 assigns rights in derivative information to Trade Me unless otherwise agreed in writing. We would not claim ownership of listing derived scores or explanations. Please confirm the ownership of those outputs and whether we could have a limited licence to calculate and display them for the approved purpose. Our independently developed software and general ranking method would remain separate, subject to an agreed definition of derivative information. Scores would not be retained.

Would you approve this purpose and the necessary display, comparison and derivative permissions in writing, with attribution, rate limits and termination conditions? If this use is outside your policy, please let us know. We would not substitute website scraping for an API refusal.
